# Simple Semantics

**Simple Semantics** is a totally A.I.-powered language manipulation game made for fun and learning.

You are a royal messenger in a fantasy kingdom, and your job is to deliver messages through different people across the kingdom. Each person has a unique personality and will manipulate the message according to their own nature. Before sending the message, you must rewrite the original text so that neither the characters nor the banned words reveal its meaning directly.

It sounds simple, but can you master semantics and become the ultimate messenger of the kingdom?

## How to Play

At the start of the game, a message appears along with a list of banned words.

Example:

> "Queen should not hold meeting in balcony tomorrow, pillar may fall"

**Banned words:** balcony, pillar, tomorrow, fall

Your task is to manipulate the message without using any banned words.

The A.I. will evaluate your answer.

### Winning Conditions

Simply manipulating the message does not guarantee victory.

What matters is whether the Queen understands the message.

* If your message is poorly written but the Queen still understands it, you will receive **25% points**.
* If your message is correctly manipulated but the Queen cannot understand it, you will receive **0 points**.

## Installation

Since the game uses CORS requests for the A.I. API, you must install it on a supported operating system.

Download it from [here](https://basic-bitch-foundation.itch.io/simple-semantics).
